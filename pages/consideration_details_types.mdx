# ConsiderationDetails Types

The `ConsiderationDetails` type system represents the various chunks of legal sources and documents returned by the Legal Research API. Each type is a discriminated union member keyed by its `label` field.

---

| File | Purpose |

| `shared/types/consideration-details.types.ts` | All detail types + union type |
| `shared/types/omnilex-file.types.ts` | `OmnilexFileFolderFile`, `OmnilexFileInternal` |

Defined in `shared/db/casesdb/src/filesUtils.ts`. Represents a single paragraph extracted from a PDF/document.

```typescript

  content?: string; // Optional – omit when storing references to reduce payload size

  spans?: {
    offset: number;
    length: number;
```

## Base Type

Every consideration detail shares this structure:

```typescript
export type ConsiderationDetailsBase = {
  /** Discriminant – use this to narrow the type */
  label: ConsiderationType;

  /**
   * Grouping key in the frontend.
   * All chunks belonging to the same logical object (e.g. same article, same court decision)
   * must share the same title.
   */
  title: string;

  /** Unique citation string identifying this exact chunk (e.g. "Art. 54 VRV") */
  citation: string;

  /** Text content of the chunk */
  content: string;
};
```

> **Breaking change vs. previous API version**
> - `citations: string[]` → replaced by `citation: string` (single string, not an array)
> - `content: string[]` → replaced by `content: string` (single string, not an array)
> - `relevant_ids: number[]` → removed entirely

## Union Type

```typescript
export type ConsiderationDetails =
  | FederalArticleChunkDetails
  | CantonalArticleChunkDetails
  | CommunalArticleChunkDetails
  | CommentaryChunkDetails
  | CourtDecisionChunkDetails
  | CaseFileChunkDetails
  | InternalFileChunkDetails
  | WebpageChunkDetails
  | ZefixCompanyChunkDetails
  | SwissregTrademarkChunkDetails;
```

The `label` field is the discriminant for exhaustive narrowing.

## Usage Example

```typescript
import { ConsiderationDetails, ConsiderationType } from '@shared/types';

function processConsideration(detail: ConsiderationDetails) {
  // Common properties available on every type
  console.log('Type:     ', detail.label);
  console.log('Title:    ', detail.title);
  console.log('Citation: ', detail.citation);
  console.log('Content:  ', detail.content);

  switch (detail.label) {
    case ConsiderationType.FederalArticleChunk:
    case ConsiderationType.CantonalArticleChunk:
    case ConsiderationType.CommunalArticleChunk:
      console.log('Law URL:', detail.url);
      break;

    case ConsiderationType.CommentaryChunk:
      console.log('Publisher:', detail.publisherName); // "staempfli" | "omnilex"
      console.log('URL:', detail.url);
      break;

    case ConsiderationType.CourtDecisionChunk:
      console.log('Caption:', detail.caption);
      console.log('Related articles:', detail.articleOrParagraphCitations.join(', '));
      break;

    case ConsiderationType.CaseFileChunk:
      console.log('File name:', detail.file.name);
      console.log('Case folder:', detail.file.caseFolderId);
      detail.paragraphs.forEach((p) => console.log('Paragraph:', p.content));
      break;

    case ConsiderationType.InternalFileChunk:
      console.log('File name:', detail.file.name);
      console.log('CMS path:', detail.file.fileCmsPath);
      detail.paragraphs.forEach((p) => console.log('Paragraph:', p.content));
      break;

    case ConsiderationType.WebpageChunk:
      console.log('URL:', detail.url);
      break;

    case ConsiderationType.ZefixCompanyChunk:
      console.log('UID:', detail.uid);
      console.log('Status:', detail.status);
      console.log('Legal seat:', detail.legalSeat);
      break;

    case ConsiderationType.SwissregTrademarkChunk:
      console.log('Trademark:', detail.trademarkName, '#', detail.trademarkNumber);
      console.log('Holder:', detail.holder);
      break;
  }
}
```
